A ROS 2 skid-steer robot simulated in Gazebo. Includes the URDF/xacro model, Gazebo and RViz launch files, a ROS-Gazebo bridge config (`/clock`, `/cmd_vel`, `/odom`, `/tf`), a saved map, and a Python goal-sending node.
